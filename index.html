しくみ (使っている音響モデル)
  • 気候: 地域の月平均気温・湿度 → 時間帯と天気で気温を動かし、水蒸気圧を保って湿度を再計算。標高から気圧。
  • 音速: c = 331.3·√(1 + T/273.15) (+湿度補正)
  • 空気吸収: ISO 9613-1 (気温・湿度・気圧から周波数ごとの dB/m)
  • 地面: Delany–Bazley の地面インピーダンス (流れ抵抗 σ) と、球面波反射係数 Q = Rp + (1−Rp)F(w) (Faddeeva 関数)。観客エリアでは人の頭の高さを吸音面として扱う。
  • 柵・スタンド・ビル: Kurze–Anderson の回折減衰 (フレネル数 N = 2δ/λ) と壁の透過損失。
  • ラインアレイ: J 型アレイのまっすぐな上部 (全長の約 1/3) だけが円筒波 (−3 dB/倍距離) を出し、L²f/2c より遠くは球面波 (−6 dB/倍距離)。サブは無指向/カーディオイド。ディレイタワーは時間合わせ (+10 ms)。
  • システム調整: 各スピーカーを FOH (またはタワーの担当位置) でターゲット特性に EQ。FOH = 100 dB(A)。
  • 屈折: 風と気温勾配から実効音速勾配 → 上向き屈折の影領域 / 夜の逆転層や追い風で遠くまで届く。
  • 乱流: 直接音と地面反射の干渉を風の強さと距離でぼかす。遠くでは音量がゆらぐ。
  • 散乱: 客席より外では木・建物・車・屋台で高い音ほど散らされる (ISO 9613-2 付属書 A の樹木の表を周辺環境ごとに倍率をかけて使用)。
  • 反射: ビル・スタンド・山・木立の 1 次鏡像音源。
  • 残響: 会場 (Sabine + 空気吸収) と周辺環境の拡散音。会場外へは縁を回折して漏れる。
  • 頭: Brown–Duda 球頭モデル (両耳の時間差・頭の影)。
  • これらから 4ch (L→左耳, L→右耳, R→左耳, R→右耳) のインパルス応答を作り、歩くたびに作り直して畳み込みます。
